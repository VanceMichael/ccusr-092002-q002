# 领域资料

参访记录、招商政策及企业授权分别由园区、招商主管部门与来访企业保存，跨区联系需保留受理方信息。

`contracts/entities.json` 保存外部数据的首批交换字段。来源编号仅表示提交方对同一记录的识别符，示例文件不包含真实个人资料。运行时持久化文件由 `DATABASE_PATH` 决定；时间字段使用带时区偏移的 ISO 8601 字符串。

## 归口规则

交流周结束后，台商、台青与区县招商人员可能围绕同一次走访分别提交合作意向。服务以参访行程（`visit_ref`）与企业（`enterprise_ref`）为锚点做归口：同一企业同一走访的后续提交不再新建意向，而是作为来源记录（`source_record`）并入既有意向；不同来源对同一条件字段给出不同取值时，自动生成分歧（`dispute`）留待经办人处理，分歧未处理完毕不得签约。

## 状态与权限

意向状态机为 `draft → published → signed`，另有终止态 `closed`。企业在意向公开（`published`）前可调整合作范围；公开后调整请求被拒绝。经办人只能处理所属园区的材料，身份通过请求头 `X-Actor-Kind` / `X-Actor-Id` / `X-Actor-Park` 声明，企业方使用 `X-Actor-Kind: enterprise` 与 `X-Actor-Enterprise`。

跨区转交由当前园区经办人发起，处于 `pending` 状态的转交须由接收园区经办人确认；确认时留下包含接收人、接收园区与接收时间的回执（`receipt`），意向归属园区随即变更，原园区经办人不再拥有处理权限。

## 政策版本与签约

园区优惠政策按版本登记（`park_ref` + `revision`）。意向创建时记录当时确认的版本；签约前若园区已生效更新的版本，签约请求被拒绝并提示重新确认（`policy_reconfirm_required`），由经办人或企业方确认到新版本后方可签约。

## 对外清单与追溯

对外合作清单只包含已公开或已签约的意向，且联系人仅保留企业方凭 `consent_ref` 授权同意的条目；未获同意的联系人不出现在清单中。每个意向的全部留痕——来源记录、实地对接、分歧提出与处理、转交回执、政策确认与状态变更——都写入事件流，可从项目状态经追溯接口完整还原。
